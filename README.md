# Toy Car To Real Car Skill

A small [SKILL.md](./SKILL.md) package that helps AI coding assistants guide users through [Toy Car To Real Car](https://toycartorealcar.com/) — a free online AI video tool that turns one car photo into a miniature-to-full-size night-road reveal.

## What it does

- Explains how to pick a clear car photo and run the prepared effect
- Covers upload → generate → preview → download on the web product
- Points assistants to the live tool at [https://toycartorealcar.com/](https://toycartorealcar.com/)

## Install

```bash
git clone https://github.com/OmniVideo/toy-car-to-real-car-skill.git
```

Then load `SKILL.md` in your Claude Code / Codex skills directory, or follow your assistant's skill install steps.
